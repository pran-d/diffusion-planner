\section{Method Coverage Map}

For completeness, the following method components are covered in the manuscript:
\begin{itemize}
\item data acquisition, SBTO processing, and trajectory windowing;
\item egocentric transforms and yaw-invariant representation;
\item discrete diffusion formulation and DiT-1D denoiser architecture;
\item in-distribution reconstruction and OOD goal-reaching evaluation;
\item stitching-related drift and kinematic-consistency limitations;
\item feature-wise partial masking for decorrelation and compositional generalization;
\item group-wise input embedding for heterogeneous feature channels;
\item masked in-betweening with RePaint-style resampling;
\item left-right mirror symmetry augmentation in the dataset pipeline.
\end{itemize}
